# Partnership Images

This directory contains images used on the Strategic Partnerships page.

## Required Images

For the Glass Slit Reveal component on the Strategic Partnerships page, you need:

1. **student-lab.jpg** (16:9 aspect ratio recommended)
   - Shows an Ennova engineering student working in a lab, workshop, or study environment
   - Should convey: learning, building, innovation, technical work
   - Suggested scenes: student at computer, working on hardware, in a lab coat, at a whiteboard, etc.

2. **professional-office.jpg** (16:9 aspect ratio recommended)
   - Shows a professional working in a corporate office environment
   - Should convey: success, leadership, delivery, professional excellence
   - Suggested scenes: business meeting, professional presentation, office environment, etc.

## Image Specifications

- **Aspect Ratio**: 16:9 (1920x1080px or similar)
- **Format**: JPG or PNG
- **Size**: Optimized for web (< 500KB recommended)
- **Quality**: High resolution for retina displays

## Fallback

If images are not provided, the component will display beautiful gradient backgrounds with emoji icons and descriptive text as placeholders.

## Adding Your Images

1. Place your images in this directory (`/public/images/partnerships/`)
2. Name them exactly as specified above
3. The component will automatically load them

## Example Sources

You can use:
- Stock photos from Unsplash, Pexels, or similar
- Professional photos from your organization
- Generated images from AI tools like Midjourney or DALL-E
